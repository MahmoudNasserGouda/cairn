# Open Source Compass

Helps students, junior developers, and developers in emerging markets **discover**
suitable open-source projects, **understand** unfamiliar codebases, **contribute**
meaningfully, and **turn contributions into professional opportunities**.

Local-first, zero-cost, security-first. The core product runs entirely in the browser —
no backend, no database, no OSC-funded AI (bring your own key).
